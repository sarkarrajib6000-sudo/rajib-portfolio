# Project Context: Rajib Portfolio Website

## Objective
Build a production-ready, responsive personal portfolio website using React, TypeScript, Vite, Tailwind CSS v3, Framer Motion, and Lucide React.

## Stack Details
- **Frontend Framework**: React 19 (as seen in package.json)
- **Styling**: Tailwind CSS v3 (postcss.config.js, tailwind.config.js, index.css)
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Tooling**: Vite
- **Testing**: Vitest (to be installed/integrated in Milestone 1)
- **Linter**: Oxlint (pre-configured)
